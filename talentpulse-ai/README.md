# TalentPulse AI — скоринг вакансий и генератор гайда интервью

R&D-прототип AI-инструмента для HR-команд и нанимающих менеджеров (собрано с помощью Claude Code).

## Задача

Рекрутер вставляет текст вакансии и резюме кандидата и за секунды получает:

- **Match Score 0–100%** с разбивкой (ключевые компетенции, опыт, «будет плюсом», измеримые результаты);
- **сильные совпадения**: подтверждённые компетенции;
- **зоны риска**: что проверить на интервью (пробелы, недостаток стажа, уровень английского, отсутствие цифр в резюме, «базовые» навыки);
- **5 персонализированных вопросов** для интервью с подсказкой, что слушать в ответе;
- **готовый промпт для Claude** для глубокого разбора: матрица соответствия, риски, гайд на 8 вопросов, тестовое задание.

## Режимы работы

| Режим | Как работает |
|---|---|
| Быстрый локальный анализ | Словарь из ~18 продуктовых и технических компетенций (RU/EN синонимы), разбор требований и блока «будет плюсом», подсчёт стажа по датам в резюме. Работает офлайн, данные не покидают браузер. |
| Live LLM API | `POST {base}/chat/completions` (OpenRouter, OpenAI или свой OpenAI-совместимый endpoint), ответ в JSON. Если ключа нет, API вернул ошибку, истёк таймаут 45 с или ответ не разобрался, автоматически включается локальный движок. |

## Стек

- Один файл `index.html`: HTML5 + CSS + ванильный JavaScript, без сборки и зависимостей (только шрифт Inter из Google Fonts, с fallback на system-ui).
- Адаптивная вёрстка: 2 колонки на десктопе, 1 на мобильных.
- API-ключ хранится только в памяти вкладки.

## Деплой на GitHub Pages

1. Положите `index.html` и `README.md` в корень репозитория.
2. Settings → Pages → Source: *Deploy from a branch*, ветка `main`, папка `/ (root)`.
3. Через минуту сайт будет доступен по адресу `https://<username>.github.io/<repo>/`.

Локально достаточно открыть `index.html` в браузере.

## Продуктовая гипотеза

**Проблема.** HR-специалисты и нанимающие лиды тратят 15–20 минут на первичный разбор каждого отклика, а вопросы для интервью каждый раз придумывают заново, поэтому кандидатов трудно сравнивать между собой.

**Гипотеза MVP.** Автоматический скоринг и гайд интервью, собранный по выявленным пробелам, сократят время скрининга до 2 минут на отклик и стандартизируют интервью.

**Метрики проверки:**

- **Time-to-Screen**: медианное время от открытия отклика до решения «звать / не звать» (цель ≤ 2 мин).
- **Share of Relevant Interviews**: доля интервью, после которых кандидат проходит дальше (не ниже базовой линии).
- **Retention рекрутера**: доля рекрутеров, которые пользуются инструментом на 4-й неделе (цель ≥ 40%).

> Скоринг носит рекомендательный характер: решение о найме принимает человек.
